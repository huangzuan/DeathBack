# ⚰️ Death Back

![Minecraft Version](https://img.shields.io/badge/Minecraft-1.21.1-brightgreen)
![Mod Loader](https://img.shields.io/badge/Loader-NeoForge-blue)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

A Minecraft mod developed using MCreator that allows players to quickly teleport back to their last death location.

---

## ✦ Features

* **Death Point Tracking**: Automatically records precise coordinates and dimensions whenever a player dies.
* **Quick Teleportation**: Easily teleport back to the death location using in-game commands or triggers to recover items.
* **Cross-Dimensional Travel**: Fully supports cross-dimensional teleportation across the Overworld, the Nether, and the End.

---

## 🛠️ Open Source & Developer Notes

This mod was built using **MCreator**. Feel free to inspect, modify, or learn from the code!

* `src/`: Generated Java source code.
* `elements/`: MCreator procedure logic and workspace configurations.
* `death_back.mcreator`: The main MCreator project file (can be imported directly into MCreator).
